# 🤝 Contributing to Smart Keyboard

Thank you for your interest in contributing! 🚀
This project is designed for **beginners to learn Android development + Git workflow**.

---

## 🧠 How to Contribute

1. Fork this repository

2. Clone your fork

3. Create a new branch:

   git switch -c feature/your-feature-name

4. Make your changes

5. Commit your changes:

   git commit -m "Add: your feature description"

6. Push your branch:

   git push origin feature/your-feature-name

7. Open a Pull Request → target branch: `dev`

---

## ⚠️ Important Rules

* ❌ Do NOT push directly to `main`
* ❌ Do NOT push directly to `dev`
* ✅ Always create a Pull Request
* ✅ Keep changes small and focused
* ✅ Write clear commit messages

---

## 💡 Beginner-Friendly Ideas

If you're new, you can start with:

* Improve keyboard UI
* Add new emojis
* Fix bugs
* Improve suggestion system
* Add themes (dark/light)

---

## 🧪 Workflow Overview

feature → dev → main

---

## 🙌 Need Help?

Open an issue or ask questions in your PR.
Learning is the main goal here!
